# HopZero Commercial Licensing & Support Architecture

## 1. Dual-License Model

HopZero operates on a transparent dual-licensing structure designed for both open-source security research and high-assurance commercial enterprise deployments:

1. **HopZero Community Edition (Apache 2.0)**:
   - Free, unencumbered open-source distribution under the Apache 2.0 license.
   - Includes core deterministic forensic parsing, 41-rule qualification registry, 9-bucket capped scoring, and local progressive disclosure UI.
   - Permitted for academic research, personal triage, non-profit organizations, and evaluating organizations.

2. **HopZero Commercial Enterprise Edition**:
   - Designed for corporate Security Operations Centers (SOCs), Managed Security Service Providers (MSSPs), financial institutions, and government digital forensics laboratories.
   - Unlocks enterprise multi-seat pooling, high-throughput GPU worker pools, PostgreSQL multi-tenancy, custom qualification registry overrides, priority incident response SLAs, and indemnification protection.

## 2. Air-Gapped Offline License Verification

Consistent with our strict **Zero-Telemetry** invariant, HopZero commercial licenses **never contact a license server, phone home, or require internet connectivity**.

### License Key Token Format
```
HZ-<EDITION>-<PAYLOAD_BASE64>-<HMAC_SHA256_SIGNATURE>
```
The token encapsulates:
- Customer organization identifier (`customer_id`).
- Licensed edition (`Lite`, `Standard`, `Pro`, `Server`).
- Number of authorized analyst seats (`max_seats`).
- Entitled feature flags (`features`).
- Expiration timestamp in UTC (`expires_at`).
- Cryptographic HMAC-SHA256 signature generated by the HopZero Master Licensing Authority.

### Offline Deployment Methods
1. **Environment Variable**: Set `HOPZERO_LICENSE_KEY="HZ-PRO-..."` on the target server.
2. **Local Key File**: Place the key string into `%LOCALAPPDATA%\HopZero\license.key` (or `~/.local/share/hopzero/license.key`).

If no commercial license key is provided, the software gracefully defaults to the fully-functional Community/Evaluation tier without disabling forensic scoring.
